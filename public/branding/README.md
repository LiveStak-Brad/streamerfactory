# Streamer Factory Brand Assets

Approved identity from `public/sflogo.png` + `public/masterbrandboard.png`.

Regenerate all derived assets:

```bash
npm run generate:brand
```

## Structure

| Folder | Purpose |
|---|---|
| `logo/` | Primary logo, SF mark (SVG/PNG), mono variants |
| `favicon/` | favicon.ico, 16–512 PNG, apple-touch, mask, PWA, Windows tile |
| `og/` | Open Graph images (homepage, join, rankings, …) |
| `social/` | Instagram / TikTok / YouTube / Discord templates |
| `icons/` | Feature icon family (SVG) |
| `badges/` | Achievement badges |
| `medals/` | Rank medals (1st–Champion) |
| `empty-states/` | Branded empty illustrations |
| `avatars/` | Default creator avatar |
| `loading/` | Loader mark |
| `splash/` | Desktop / tablet / phone / PWA splash |
| `emails/` | Email header logo |
| `watermarks/` | Dark / light / minimal watermarks |
| `backgrounds/` | Gradient mesh + particles |
